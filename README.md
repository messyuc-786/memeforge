It takes **one simple thought or prompt** and instantly transforms it into a complete **Content Multi-Verse Pack** — including image memes, multi-tone variations, 9:16 vertical video reels, and ready-to-post social copy for X, WhatsApp, and Instagram.

## ✨ Key Features

### 🌌 1. Content Multi-Verse Engine (1 Idea → 10 Formats)
Type a single idea (e.g. *"When your manager says the meeting will only take 5 minutes"*), and MemeForge automatically creates:
- 🔥 **Classic Meme**: Standard viral meme layout.
- 😂 **Everyday Relatable**: Peak relatable situational meme.
- 💀 **Savage Burn**: Unfiltered comedic roast meme.
- 🇮🇳 **Desi / Hinglish**: Indian pop-culture & colloquial meme.
- 💼 **Corporate Satire**: Office & workplace humor.
- 🤪 **Absurd / Unhinged**: Gen-Z surreal meme punchline.
- 🎥 **9:16 Vertical Video Reel Script**: Hook overlay + recommended audio soundtrack.
- 📱 **Social Multi-Pack**: Formatted X tweet, WhatsApp 1-liner, and trending hashtags.

### 🧬 2. Meme DNA & AI Creative Score (0–100)
- Analyzes meme humor traits: Emotion, Tone, Target Audience, Topic, Format, Energy, and Shareability.
- Provides actionable AI tips to maximize engagement and virality.

### 🔄 3. 10-Way Instant Remix Engine
- 1-Click transformation preserving original context: *Swap Template, More Savage, More Wholesome, More Absurd, Gen-Z Slang, Desi/Hinglish Mode, Punchy 1-Liner, Convert to Video*.

### 🎥 4. 9:16 Video Meme Studio
- Create TikToks, Instagram Reels, and YouTube Shorts with custom top/bottom text banner overlays.
- Real-time video player with speed controls (0.5x, 1x, 1.5x, 2x) and AI hook generator.

### 🤳 5. "Put Me In The Meme" Personalization
- Upload any selfie to automatically crop, feather, and paste your face into iconic meme formats.

### 🇮🇳 6. Desi / India Meme Studio
- Curated presets celebrating Bollywood, Cricket, Shaadi rishtas, Chai breaks, and Sharma Ji Ka Beta.

### 🎨 7. Pro Canvas Meme Studio & GPU Shaders
- **Drag-and-Drop Canvas**: Multi-layer text strokes, draggable speech bubbles with directional tail pointers, rich sticker library, and neon glow drawing brush.
- **6 GPU Cartoon Shaders**: *Cute Cartoon, Comic Book, Pixar 3D, Pencil Sketch, Deep Fried Dank, and Anime Cel-Shade*.

### 🔊 8. Meme Soundboard Synthesizer
- Built-in Web Audio API sound effects: *Vine Boom, Airhorn, Pop, Sparkles, and Victory Chime*.

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/messyuc-786/memeforge.git
cd memeforge
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run local dev server
```bash
npm run dev
```
Open **[http://localhost:5173](http://localhost:5173)** in your browser.

### 4. Build for Production
```bash
npm run build
```
